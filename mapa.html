🎮 COMO USAR ESTE MAPA
1. MAPA — Veja todas as fases organizadas por mundo. Clique em qualquer node (exceto 🔒 bloqueados) para abrir os detalhes, checklist e prompt.

2. CHECKLIST — Dentro de cada fase, clique nas tarefas para marcar como concluído. O progresso salva automaticamente no seu navegador.

3. PROMPTS — Cada fase tem um prompt pronto para copiar. Cole no Claude sempre iniciando com: "sou o Juan, Tudo Cozinha, estou na fase X"

4. FASES VERMELHAS ► — Em andamento. Foco aqui agora.

5. FASES 💳 — Bloqueadas por pagamento. Quando pagar, avisa o Claude e desbloqueamos juntos na próxima versão do app.

6. ATUALIZAR — Quando uma fase evoluir, me avisa no Claude. Gero o código novo e você substitui o mapa.html no GitHub. Simples assim.

7. PARCERIA — Juan lidera com visão + Deus na frente + Claude estrutura + Sidekick executa no Shopify. Esse esquema nunca muda.
